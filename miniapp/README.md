# ProjectHub

Telegram Mini App в стиле приложенного изображения: адаптивный главный экран, демонстрационный каталог, поиск, фильтры, избранное и форма заявки.

## Предпросмотр

Из этой папки: `python3 -m http.server 8080 --directory dist`, затем http://localhost:8080.

## Telegram-бот

Создайте бота командой /newbot в @BotFather. Полный токен содержит числовой ID, двоеточие и секретную часть. Переданный в чате короткий ключ этому формату не соответствует; он не включён в исходники.

Опубликуйте содержимое dist на публичном HTTPS-хостинге. Приватный Sites-предпросмотр предназначен для проверки владельцем: он не является готовым публичным адресом для пользователей Telegram.

Задайте переменные окружения TELEGRAM_BOT_TOKEN, MINI_APP_URL и, при необходимости, ADMIN_CHAT_ID. Запустите `python3 bot/bot.py`. Сервер бота должен работать постоянно. Пример .env.example — шаблон; скрипт читает окружение, а не .env-файл.

Откройте /start в личном чате бота, затем кнопку «Открыть ProjectHub» в клавиатуре. Именно этот способ поддерживает Telegram.WebApp.sendData. Бот принимает заявку и при настроенном ADMIN_CHAT_ID пересылает её менеджеру. Без менеджера бот явно сообщает это пользователю. Скрипт не меняет существующий webhook: для long polling webhook должен отсутствовать.

Избранное и черновики локальны для устройства. Заявки, отправленные через Telegram, остаются в переписке, а не в локальной истории черновиков. Реальных кейсов, цен и подтверждённых бизнес-показателей пока нет: каталог демонстрационный.

Документация: https://core.telegram.org/bots/webapps и https://core.telegram.org/bots/api.
